# jp-review

일본어 복습 허브 (개인 학습용) — 출근길 30분 자동재생 복습.

## 앱

브라우저로 [GitHub Pages](https://turnup43.github.io/jp-review/) 접속하거나 각 파일을 직접 엽니다.

| 앱 | 원본 | 문항 |
|----|------|------|
| [pattern202.html](pattern202.html) | 시원스쿨 일본어 패턴 202 (1~50강) | 337문장 |
| [speaking.html](speaking.html) | 시원스쿨 일본어 기초말하기 (1~30강) 종합 실습본 | 130문장 |
| [sentences.html](sentences.html) | 왕초보 1~3단계 문장정리 (Lv.1~3) | 53패턴 |
| 단어장 | 무따기 25.01 교재 → [jp-vocab](https://turnup43.github.io/jp-vocab/) | 3,392단어 |

## 공통 기능

- **KO→JP / JP→KO** 두 학습 모드 (기본 KO→JP 순간작문)
- **자동재생** — 카드마다 발음 N회(1·2·3·5, 기본 3회) 반복 후 다음 카드로 자동 진행
- **강/레벨별 필터**, **익힘 표시 + 미완만 필터** (SRS), 진도 localStorage 저장
- 발음(Web Speech API) · 속도 0.5~1.25×
- 키보드: `Space` 뒤집기 · `←/→` 이동 · `S` 발음 · `A` 자동재생 · `K` 익힘

## 메모

- 원본 문서의 OCR/입력 오류(일본어에 한글 조사·`입니다` 혼입, 손상 셀)는 표준 교재형으로 보정함.
- 발음용 텍스트는 후리가나 괄호를 제거해 TTS가 자연스럽게 읽도록 처리.
