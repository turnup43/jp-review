이 글은 학습 플래너의 각 부분이 왜 그렇게 짜였는지를 설명합니다. 그대로 따르기만 해도 되지만, 원리를 알면 스스로 조정할 수 있습니다.

1. 무엇이 문제였나

작년 가을부터 성실히 강의를 들었는데 체화가 안 된 이유는 하나입니다.

인풋(듣기)은 충분했고, 인출(꺼내기)·출력(말하기)이 없었다.

왕초보 1~3단계 · 기초말하기 · 패턴202 초반은 같은 N5 문법(명사 です → 형용사 → 동사 ます/ない/て/た)을 세 번 이상 반복합니다. 그래서 "들으면 아는데 직접 못 만드는" 상태가 됩니다. 이걸 친숙성 착각(fluency illusion) — 익숙함을 실력으로 착각하는 것 — 이라고 부릅니다.

그래서 대전제는 하나: 인풋:복습 비율을 약 90:10 → 30:70으로 뒤집는다. 새 강의를 더 듣는 게 아니라, 이미 들은 것을 입으로 꺼내는 훈련으로 전환한다.

2. 심어둔 6가지 학습 원리

① 인출 연습 · Testing Effect

다시 듣기는 친숙함만 키우고, 스스로 답을 만들어내는 행위가 기억을 만든다.

→ 반영: 매일 과제가 전부 복습앱 카드(답을 떠올리는 형식). 강의 재청취는 금지.
② KO→JP 기본값 · 순간작문

쉬운 JP→KO(인식)보다 어려운 KO→JP(생성)가 훨씬 남는다. 살짝 버거운 부하가 학습을 만든다(바람직한 어려움).

→ 반영: 앱 기본 모드 KO→JP. 모든 출근 과제가 "한국어 보고 일본어 만들기" — 실제 회화 방향과 동일.
③ 간격 반복 · SRS

맞힌 걸 계속 보는 건 낭비, 틀린 것만 다시 보는 게 효율.

→ 반영: 앱의 익힘/모름 + 미완만 필터가 곧 복습 엔진. 루틴 첫 3분이 "어제 모름 재시도". 별도 암기앱 불필요.
④ 인터리빙

한 코스씩 끝내지 말고 섞어서 돌릴 때 변별력·전이가 오른다.

→ 반영: P1에서 문장정리·기초말하기·패턴202를 번갈아 배치. P2도 신규와 기존 미완을 교차.
⑤ 출력 피드백 루프

카드로 꺼내는 것과 입으로 말하는 건 다르다. 말해봐야 막히는 지점(오류 신호)이 드러난다.

→ 반영: 매주 토요일 AI 스피킹으로 그 주 패턴 발화. 막힌 표현은 다음 주 복습 대상으로 순환.
⑥ 쉐도잉

자동재생 3회 반복은 배경음악이 아니라 입으로 3번 따라 말하라는 신호. 운율·속도·발음이 이때 자동화된다.

→ 반영: 출근 20~30분 슬롯이 "약한 강 자동재생 쉐도잉". 운전 중이면 소리만으로도 성립.

3. 구조가 곧 방법이다

매일 30분 = 고정 루틴 (의지가 아니라 습관)

시간활동원리
0~3분어제 '모름' 카드 재시도③
3~20분오늘 세트 KO→JP · 자동재생 3회 · 따라 말하기①②⑥
20~30분약한 강 자동재생 쉐도잉⑥

핵심은 매일 같은 시간(출근길)에 같은 순서로 한다는 것. 동기가 좋을 때만 하는 게 아니라, 출근이라는 고정 신호에 학습을 묶어(실행 의도) 자동으로 굴러가게 만든다.

주간 리듬 = 인출(평일) + 출력(주말)

  • 평일 5일 = 출근길 인출·쉐도잉 (넣은 걸 꺼내는 날)
  • 토요일 1일 = ㉮ AI 스피킹 발화 ㉯ 신규 강 → 핵심 5문장 카드화 ㉰ 격주 익힘% 기록

신규는 "소비"가 아니라 "변환"만

동영상 만료(2027-06)가 있다고 강의를 완주하려는 건 매몰비용 함정. 그냥 보면 또 인식만 남는다. → 새 강의는 핵심 5문장만 카드로 변환 → 다음 주 출근길 복습에 편입. 보는 것과 남기는 것을 분리한다.

4. 4단계(Phase)의 논리 — 왜 이 순서인가

Phase기간의도왜 이 순서
P0 진단1주3앱 전량 1회전하며 모름 마킹측정 먼저. 약점을 알아야 시간을 옳게 쓴다. 신규 강의 중단·AI스피킹 세팅
P1 체화6주겹치는 N5 코어를 KO→JP로 자동화세 번 들은 기초를 먼저 "소유"로 전환. 복습앱 691문장 전량 1차 통과
P2 확장8주패턴202 71강~(영상)·회화끝장·단어기초가 자동화된 다음에 새 범위 확장. 그래야 새 것도 붙는다
P3 운용8주쉐도잉+AI스피킹 유지·실전 회화유지 모드. 상황별(식당·쇼핑…) 롤플레이로 실사용화
졸업 기준(측정 가능한 게이트): P1 종료 시 3앱 익힘 90%+. 숫자로 판단하니 "대충 넘어가기"를 막는다. 미달이면 P1을 1~2주 연장.

5. "빠짐없이" — 분량 커버리지

플래너는 복습앱 691문장(문장정리 53 + 기초말하기 130 + 패턴202 404)을 하나도 빠뜨리지 않도록 설계됐다.

  • P0 전량 1회전(진단) → P1 전량 KO→JP 1차 통과(문장정리 3일 + 기초말하기 6일 + 패턴202 12일) → 이후 미완만으로 반복
  • 하루 분량은 30분에 맞춰 20~35문장. 강 라벨·문장 수를 칸마다 표기 → "오늘 어디까지"가 명확
  • 별도 트랙: 단어(코어 800 우선), 패턴202 61~70강(영상 → 주말 노트화), 71강~(영상 → 발췌 카드화)

6. 매일 이렇게 쓰세요

  1. 출근길에 허브 열기 → 오늘 칸의 앱·범위 선택
  2. KO→JP 모드, 자동재생 3회, 입으로 따라 말하기 — 모르면 모름, 알면 익힘
  3. 도착 직전 약한 강 하나 자동재생으로 쉐도잉
  4. 토요일: AI 스피킹으로 그 주 패턴 발화 → 막힌 건 다음 주 미완으로
  5. 격주 토요일: 앱 홈의 익힘% 3개를 진도추적 시트에 기록
"들어서 아는 문장"을 "입에서 나오는 문장"으로 바꾸는 6주.
